# Relative Difference in Cosine Similarity (RDCS)

This repository contains the implementation of the **Relative Difference in Cosine Similarity (RDCS)** metric, introduced in the paper "_ArGAN: Arabic Gender, Ability, and Nationality Dataset for Evaluating Biases in Large Language Models_".
